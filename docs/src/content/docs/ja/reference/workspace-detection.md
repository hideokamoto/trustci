パターンは、次のうちパターンが 1 つ以上得られた最初のものから読み込みます。

1. `pnpm-workspace.yaml`（`packages:`）
2. `package.json`（`workspaces`。配列、または `workspaces.packages`）
3. `lerna.json`（`packages`。フィールドがなければ `["packages/*"]`）

どれからもパターンが得られない場合は、ルートの `package.json` を単一パッケージとして扱います。

## パターンの書き方

パターンはリポジトリのルートからの相対パスです。

- `*` は 1 階層の中で、`?` は任意の 1 文字に一致します。
- `**` は任意の階層数に一致します。`apps/**` は `apps` 自身にも一致します。
- 先頭の `!` は、他のパターンに一致したディレクトリを除外します。

`node_modules`、`.git`、`dist`、`build`、`coverage`、`.turbo` は探索しません。

一致したディレクトリの `package.json` に空でない `name` がある場合に、パッケージとして
扱います。同じパッケージ名のディレクトリが 2 つある場合は、パス順で最初のものを使います。

## 登録対象になるパッケージ

`"private": true` のパッケージは常に除外され、その後 `--only` / `--exclude` が適用されます
（[オプション](/ja/reference/options/)を参照）。本番実行（dry run 以外）では、まだレジストリに
公開されていないパッケージは警告を出してスキップします。

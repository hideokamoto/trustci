## コマンド

| コマンド | 説明 |
| --- | --- |
| `trustci [trust] --provider <github\|gitlab\|circleci> …` | Trusted Publisher を登録します。`trust` は省略できます。 |
| `trustci list [package]` | 1 つのパッケージ、またはすべての公開ワークスペースパッケージに対して `npm trust list` を実行します。 |

## 権限

少なくとも 1 つが必須です。どちらもそのまま `npm trust` に渡されます。

| フラグ | 説明 |
| --- | --- |
| `--allow-publish` | `npm publish` を許可します。 |
| `--allow-stage-publish` | `npm stage publish` を許可します。 |

## 共通オプション

| フラグ | 説明 |
| --- | --- |
| `--dry-run` | `npm trust` コマンドを実行せずに表示します。`list` でも使えます。 |
| `--only <name-glob>` | 名前が一致するパッケージだけを対象にします（複数指定可）。 |
| `--exclude <name-glob>` | 名前が一致するパッケージを除外します（複数指定可）。 |
| `-y`, `--yes` | 確認プロンプトを省略し、`npm trust` にも `-y` を渡して npm 側の確認も省略します。標準入力が端末でない場合は必須です。 |
| `-h`, `--help` | ヘルプを表示します。 |
| `-v`, `--version` | バージョンを表示します。 |

`--only` と `--exclude` はパッケージ名全体と照合します。`*` は任意の文字列（`/` を含む）、
`?` は任意の 1 文字に一致するため、`--only '@scope/*'` でスコープ内のすべてのパッケージを
選べます。両方を指定した場合は、いずれかの `--only` パターンに一致し、かつどの `--exclude`
パターンにも一致しないパッケージが対象になります。シェルに展開されないよう、パターンは
クォートしてください。

プロバイダー固有のフラグは各プロバイダーのページに記載しています。
